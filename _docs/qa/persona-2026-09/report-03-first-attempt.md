# P03 이민지(수원 네일숍) — 1차 시도: 회원가입 429로 ABANDON

## 여정 로그
| # | 행동 | 본 것 | 초 | 마찰 |
|---|---|---|---|---|
| 1 | 가입 전 홈 카피 | 타이틀 "redoceanmap — 서울 상권 분석", 태그라인에도 "서울" | 1 | 없음(범위 고지 있음) |
| 2 | /areas 로그인 전 | 셸만 보임(클라이언트 렌더링) | 1 | 도구 한계 |
| 3~10 | 가입 6회 재시도(8·20·15초 간격, 총 211초) | 매번 `{"detail":"요청이 너무 잦습니다. 잠시 후 다시 시도해 주세요."}` | 150 | 대기 시간·원인 안내 없음 |
| 11 | 로그인으로 확인 | "이메일 또는 비밀번호가 올바르지 않습니다" — 계정 생성된 적 없음 | 1 | 가입 0회 성공 |

## 지표
```json
{"task_success": false, "steps": 11, "optimal_steps": 5, "time_to_first_meaningful_action_s": null, "friction_count": 3,
 "heuristic_violations": ["1 가시성: 429에 대기 시간·이유 없음", "9 오류 복구: '잠시 후'만 반복, 다음 행동 없음"], "abandoned": true, "chat_asks": 0}
```

## 막힌 지점
`/auth/register` 429. 병렬 QA 5세션이 같은 IP(127.0.0.1)로 동시에 가입해 걸린 레이트리밋으로 추정 — 실사용자 1명 상황과 다를 수 있어 **2차 단독 재실행** 예정. 단 사용자에게 보이는 문구("잠시 후 다시 시도")는 동일하므로 그 지적은 유효.

## 개선 제안 3개
1. 429 응답에 `Retry-After` 기반 "N초 후 다시 시도" 표시.
2. "서울 전용" 고지를 질문 입력창 placeholder에도 노출(검색 유입자가 자기 목적어에 집중할 때).
3. `/areas`를 로그인 전에도 최소 골격(SSR)으로 노출.

## 한 줄 결론
가입하려고 3분 넘게 눌러봤는데 계속 "요청이 너무 잦다"는 말만 나와서 — 네일숍이고 뭐고 그냥 나갔어요.
