## 판정 기준 (명문화 — `backtest_report.py`에 구현)

## 홀드아웃 검증 — RSI+BB ±0.35

스윕에 쓰지 않은 **이전 구간(10y 중 최근 5y 제외)**에 유일 통과 조합을 적용:

DOWN은 두 구간에서 일관성 없음(인샘플 미달, 홀드아웃 근소 상회) → 하락 예측 불가 재확인.

## 결론

1. **RSI 과매도 + 볼린저 하단(평균회귀) 결합의 UP 신호는 두 독립 구간에서 기준선 대비
   +1.9~2.1%p 적중률, Wilson 하한 기준 +0.4%p 마진으로 재현됨** — 기존 "모든 조합이
   기준선을 못 이긴다" 결론에서 한 발 전진한 첫 양성 신호.
2. 그러나 **"확률 제시"는 계속 보류**: 42회(21조합×2방향) 다중 비교에서 나온 1건이고
   하한 마진이 +0.4%p에 불과 — 사용자에게 %로 단정하기엔 근거가 얇다.
   chat 답변에는 "과매도+밴드 하단 반등 신호(참고)" 수준으로만 쓸 수 있다.
3. OBV(수급)·ATR 거부(변동성 필터)는 이 데이터에서 개선 효과 없음. 요일/시장 분리,
   피처 상호작용 등 추가 탐색은 수확 체감 — **다음 재채점은 뉴스 감성 축적(약 3개월) 후**
   감성 피처를 넣어서 한다(로드맵 데이터·모델 트랙).
4. 서비스 기본값(`AnalysisConfig.default()`)은 유지 — 실서비스는 감성이 결합되는 경로라
   중립-감성 백테스트만으로 기본 가중치를 바꾸지 않는다.

## 3차 재채점 (2026-07-14) — 12-1 모멘텀 + 거래량 확인 필터

신규 피처 2종을 추가하고 조합 3세트(×3임계값 = +9, 총 30조합·비교 60회)로 재채점.
실행 커맨드는 인샘플 `--period 5y`, 홀드아웃 `--period 10y --drop-last 1260`(최근 5y 제외,
스크립트에 재현 플래그로 명문화). 홀드아웃에서 373220(LG엔솔, 2022 상장)은 봉 부족으로
자동 스킵되어 23종목 — 인샘플(24종목)과 구성이 1종목 다름.

- **12-1 모멘텀**: 12개월 전 → 1개월 전 수익률(`closes[-22]/closes[-253]-1`, Jegadeesh-Titman).
  신호는 `clamp(momentum×2)`, 가중치 `w_momentum`. 이력 253봉 미만이면 중립 0.0 —
  스윕 초기 ~200일은 모멘텀 조합이 관망만 낸다(적중률 왜곡 없음, 표본만 감소).
- **거래량 확인 필터**: `volume_confirm` — 방향 판정 후 volume_ratio가 임계 미만이면 관망으로 강등.

### 인샘플·홀드아웃 모두 통과한 UP 신호 (판정 기준 동일: n≥100 + Wilson 95% 하한 > 기준선)

| 조합 | 구간 | UP n | UP 적중 | Wilson 하한 | 기준선 | 하한 마진 |
|------|------|------|---------|-------------|--------|-----------|
| RSI+BB ±0.35 (2차 우승) | 인샘플 | 4,564 | 53.3% | 51.9% | 51.4% | +0.5%p |
| | 홀드아웃 | 3,218 | 58.1% | 56.4% | 56.0% | +0.4%p |
| **RSI+BB+MOM(0.4/0.4/0.2) ±0.25** | 인샘플 | 6,806 | 54.0% | 52.8% | 51.4% | +1.4%p |
| | 홀드아웃 | 5,827 | 58.0% | 56.7% | 56.0% | +0.7%p |
| **RSI+BB+MOM(0.4/0.4/0.2) ±0.35** | 인샘플 | 3,924 | **56.4%** | **54.9%** | 51.4% | **+3.5%p** |
| | 홀드아웃 | 3,499 | **58.5%** | **56.9%** | 56.0% | **+0.9%p** |

### 결론

1. **평균회귀(RSI+BB)에 모멘텀을 소량(0.2) 결합한 RSI+BB+MOM ±0.35가 새 최우수 검증 신호** —
   두 독립 구간 모두 기존 우승 조합보다 두꺼운 마진(인샘플 하한 +3.5%p는 이번 스윕 최대).
   임계값 0.25/0.35 두 지점에서 연속 통과해 우연 통과보다 견고하다.
2. **모멘텀 단독은 기각**: 인샘플 3임계값 전부 통과했으나 홀드아웃 전멸(하한 55.0~55.3% < 56.0%).
   보완 신호로만 유효하다는 뜻 — 학술 팩터도 이 데이터·지평(5일)에선 단독으론 부족.
3. **거래량 확인 필터는 기각**: 표본만 줄이고(n 약 40% 감소) 적중률 개선 없음(인샘플 전 임계값 미통과).
   volume_ratio는 계산·노출만 유지하고 판정 개입은 하지 않는다.
4. **하락(DOWN) 예측 불가 재확인**: 어떤 조합도 두 구간 연속 통과 없음.
5. 60회 다중 비교에서 나온 결과이므로 **확률 제시는 여전히 보류**. 서비스 기본값도 불변(결론 4 유지).
   API 참고 신호(`reference_up_signal`)는 일단 2차 검증 조합(RSI+BB ±0.35)을 유지하되,
   RSI+BB+MOM ±0.35가 뉴스 감성 재채점(3개월 후)에서도 재현되면 참고 신호 승격을 재검토한다.

## 4차 (2026-07-30) — forecast 슬라이스 판정 조합 교체 + 하방·회복 통계

**이번은 새 스윕이 아니다.** 3차 우승 조합을 **실서비스 forecast 경로에 적용**한 기록이며,
계기는 스윕 결과가 아니라 **운영 실측 결함**이다.

### 발견 — 예측 스냅샷이 산출물을 내지 않고 있었다

| 실측 (2026-07-30, `forecast_snapshots` 전수) | 값 |
|---|---|
| 스냅샷 | 814건 — **전부 `NEUTRAL`** |
| 채점 완료 | 123건 — **전부 `hit IS NULL`**(적중 0·오답 0) |
| 최대 \|score\| | **0.2000** |
| `up_threshold` | 0.3 → **도달 건수 0** |
| `sentiment` 신호 값 | 814건 전부 0 (가중치 0.5) |
| `rsi` 신호 값 | 814건 중 764건(94%)이 0 |

원인은 버그가 아니라 **설정 불정합**이다. 이 슬라이스는 설계상 감성 중립인데
(`Backtester.distribution()`이 감성 없이 분포를 만들므로 방향도 같은 조건이어야 한다)
판정에는 **감성이 결합되는 경로용 `default()`**(감성 0.5+RSI 0.3+추세 0.2, ±0.3)를 쓰고 있었다.
감성 0.5가 사장돼 예산이 0.5뿐이고, RSI 신호는 30~70 구간에서 0이라 실질 상한이 추세의 0.2다 —
**임계 0.3에 산술적으로 도달할 수 없다.**

### 조치 — `AnalysisConfig.forecast_signal()` 신설

3차 최우수 조합(RSI+BB+MOM 0.4/0.4/0.2 ±0.35)을 forecast·스냅샷 슬라이스에 쓴다.

- **결론 4를 뒤집는 것이 아니다.** 결론 4가 `default()`를 지킨 이유는 *"실서비스는 감성이
  결합되는 경로라 중립-감성 백테스트만으로 기본 가중치를 바꾸지 않는다"*였다. **forecast
  슬라이스는 그 이유가 성립하지 않는 경로**(감성 중립)이고, 3차 조합의 검증 조건이 바로
  그 조건이다. `analyze` 경로의 `default()`는 **불변**이다.
- **하락은 방향으로 내지 않는다.** `down_threshold=-1.01`(score가 [-1,1]로 클램프되므로 도달 불가) —
  2·3차 모두 하락은 두 구간 연속 통과 조합이 없었다(결론 4·5의 "하락 예측 불가" 유지).
  대신 아래 하방 통계로 답한다.
- 호출부는 두 곳(`stock_forecast_interactor` 뷰 계산 · `forecast_snapshot_interactor` 신호 분해)이라
  **함께 교체해야 한다** — 갈라지면 저장된 `score`와 `direction`이 다른 조합으로 계산된다.
- 회귀 방지: `tests/domain/test_analysis_config.py` — 어떤 지표 조합에서도 DOWN이 안 나오는지,
  그리고 **`default()`로는 감성 없이 임계값에 못 미치는 사실**을 함께 고정한다.

### 함께 추가 — 하방·회복 통계 (방향 라벨의 대체물)

"더 떨어질까 / 회복될까"에 방향 단정 없이 답하기 위해 `Backtester.distribution()`이 기존
워크포워드 루프 **안에서** 평가일당 세 값을 함께 수집한다(루프 추가 없음).

| 값 | 정의 |
|---|---|
| `trough_median_pct` · `trough_q25_pct` | 구간 내 **장중 저가** 기준 최대 낙폭의 중앙값·하위 25% |
| `down_close_rate` | horizon 마감 수익률이 음수였던 비율 |
| `dip_samples` | 낙폭이 있었던(`trough < 0`) 표본 — **회복률의 분모** |
| `recovery_rate` · `recovery_days_median` | 그중 기준가를 **종가로** 회복한 비율과 소요 거래일 |

**회복률의 분모를 전체 표본으로 두지 않은 것이 요점이다** — 무조정 상승일을 섞으면 회복률이
부풀려져 "빠졌다 돌아왔다"는 주장이 근거를 잃는다.

현재 국면(`PositionProfile`: RSI 구간·60일 고점 대비 낙폭·지지선 여력)은 **새 지표 계산 없이**
기존 `Indicators`에서 파생한다. RSI 경계 30/70은 신호 계산과 상수를 공유해(`indicators.py`)
"과매도인데 신호는 0" 같은 모순이 화면에 뜨지 않게 했다.

### 이력 오염 방지

`forecast_snapshots.signal_config`(alembic `a1b2c3d4e5f7`)에 조합 식별자를 남긴다.
**NULL = 교체 이전 `default()` 조합**이며 **백필하지 않는다** — 그 814건은 실제로 구 조합의
판정이고, 섞어서 적중률을 집계하면 안 된다. 같은 리비전이 재적합 피처(원시 지표)와
채점 시 실측 `realized_trough_pct`(오답이 얼마나 나쁘게 틀렸는지)를 함께 추가했다.

`(ticker, horizon_days, as_of)` 유니크가 걸린 것 — 이력 오염 방지가 의도대로 작동한 결과다.
그 2건은 `earnings_veto=true`(삼성 실적 ±2일)라 `score 0.600`인데도 관망 강등됐다(설계대로).
`signal_config='forecast_signal'` 행이 본격적으로 쌓이는 것은 **다음 거래일 14:00 cron부터**다.

### 남은 것

- **적중률 관찰은 아직 불가.** 이 조합의 첫 `hit`은 5일 지평이 도래하는 1~2주 뒤부터 쌓인다.
  그 전에 `/admin/forecasts`의 숫자를 해석하지 않는다(구 조합 NULL 행이 분모에 섞이지 않는지도
  함께 확인할 것).
- **감성 재채점(결론 3의 "3개월 후")은 여전히 미실시.** 뉴스 라벨은 이미 29,509건·76종목·8개월
  축적돼 조건은 충족됐다 — 별개 안건으로 남긴다.
- `reference_up_signal` 승격도 별개(결론 5 유지).
