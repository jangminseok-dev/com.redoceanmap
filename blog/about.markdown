<div class="cn-card cn-bg-plain cn-body cn-wide" markdown="1">

- **상권**: 공공데이터 기반 상권 분석 — 지도 위에서 지역·업종을 고르면 3NF 정규화된 실데이터를 근거로 LLM이 해설합니다.
- **주식**: 시세·재무 데이터를 대화로 질의하고, 투자 지시나 확률 단정 없이 데이터 근거만 제시합니다.
- **인프라**: 온프레미스 백엔드 + 로컬 LLM(EXAONE 7.8B) — 외부 유료 API 없이 운영합니다.

</div>
