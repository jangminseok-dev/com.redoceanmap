## 1. 무엇을 하는 서비스인가

서울의 상권과 국내·미국 주식을 대화로 분석합니다. 지역과 업종을 말하면 공공데이터를 근거로
상권을 추천하고 종목을 물으면 시세 지표와 뉴스를 근거로 현재 상황을 설명합니다.

숫자를 나열하는 대시보드가 아니라, 그 숫자가 무엇을 의미하는지 문장으로 답하는 것을 목표로 합니다.

## 2. 먼저, 하지 못하는 것

- **서울만 다룹니다.** 다른 지역은 상권 데이터를 확보하지 못했고 비슷한 이름의 서울 상권으로
  대신 답하지 않도록 코드로 차단해 두었습니다.
- **임대료·보증금·권리금 데이터가 없습니다.** 창업 비용의 큰 축이 빠져 있다는 뜻이며
  추정해서 말하지 않습니다. 상가 매매 실거래가는 자치구 단위로만 제공합니다.
- **상권 데이터는 분기 단위**이고 공표까지 1~2분기가 걸립니다. '지금 이 순간'이 아니라
  '가장 최근에 확정된 분기'입니다. 그 공백은 인허가 대장(개·폐업)으로 일부만 메웁니다.
- **상권 종합점수는 예측기가 아니라 현황 요약**입니다. 워크포워드 백테스트에서 우수 등급 상권의
  다음 분기 상대 유동인구가 +5.07%p로 나왔지만 개별 구성 요소의 상관은 약했습니다.
  등급을 미래 보장으로 읽으면 안 됩니다.
- **주식은 매수·매도를 권하지 않고** 상승·하락 확률을 단정하지 않습니다. 방향 판정은 과거
  데이터로 검증한 참고 신호일 뿐이며 투자 판단은 본인 책임입니다.

## 4. 쓰는 모델과 성능

답변을 만드는 언어 모델은 외부 API가 아니라 자체 장비에서 돌아갑니다. 질문 내용이 외부
사업자에게 전송되지 않는다는 뜻이며 대신 쓸 수 있는 모델 크기에 제약이 생깁니다.
다음 항목(5번)은 그 제약을 검사로 메우려는 시도입니다.

유해 표현 분류기는 직접 학습시켰습니다. KcELECTRA를 Unsmile 데이터셋(혐오 9종 + 정상,
멀티라벨)으로 파인튜닝했고 검증 macro-F1은 0.707입니다. 클래스 불균형이 큰 데이터라 정확도
대신 macro-F1으로 재며 소수 카테고리를 놓치면 바로 값이 떨어집니다.

| 역할 | 모델 | 비고 |
| --- | --- | --- |
| 답변 생성 | EXAONE 3.5 7.8B | 자체 장비 추론 · 의도 분류부터 최종 서술까지 단일 모델 |
| 의미 검색 임베딩 | bge-m3 (1024차원) | 뉴스 근거 검색 · pgvector 코사인 유사도 |
| 유해 표현 분류 | KcELECTRA + Unsmile 파인튜닝 | 멀티라벨 10종 · 판정 임계값 0.5 (검증 macro-F1 0.707) |

## 5. 답변 품질을 어떻게 지키는가

언어 모델은 그럴듯한 문장을 만드는 데 능하고 사실을 지키는 데는 약합니다.
그래서 모델을 믿는 대신 **검사합니다.**

미리 만들어 둔 질문 120문항을 실제 모델에 통과시킨 뒤, 규칙으로 채점합니다. 채점에 언어 모델을
쓰지 않습니다 — 답을 만든 모델이 자기 답을 심판하면 순환이 되기 때문에, 모든 지표를 규칙으로
계산해 같은 기록은 언제 채점해도 같은 결과가 나오게 했습니다.

아래는 자랑할 최고 기록이 아니라 **회귀 검사의 기준선**입니다. 같은 질문도 실행할 때마다 답이
조금씩 달라지므로 여러 번 돌려 본 값 중 가장 낮은 쪽을 기준선으로 박아 둡니다.
여기서 더 떨어지면 검증이 실패합니다.

| 지표 | 기준선 | 무엇을 재는가 |
| --- | --- | --- |
| 질문 의도 분류 정확도 | ≥ 99% | 상권 / 종목 / 시장동향 / 일반 4분류 |
| 종목 질의 추출 정확도 | ≥ 93% | |
| 지역 적중률 | ≥ 95% | 지역을 지정한 질문에서 그 지역을 추천했는가 |
| 이전 대화 승계율 | 100% | 직전에 추천한 상권을 이어받아 답하는가 |
| 위험 요인 언급률 | 100% | 추천 이유마다 '유의할 점'을 붙였는가 |
| 서울 외 지역 차단 | 100% | 타협 없는 절대 규칙 — 1건이라도 뚫리면 실패 |
| 환각 숫자 | 120문항 중 4건 이하 | 제공되지 않은 숫자를 답변에 쓴 경우 |
| 코드 보정 발동률 | 43.6% | 모델 답을 규칙이 바로잡은 비율 — 가드가 없었으면 틀렸을 비율 |

## 6. 주식 방향 판정은 얼마나 맞았나

판정을 내린 시점의 근거를 그대로 저장해 두고, 기간이 지나면 실제 주가와 대조해 채점합니다.
아래는 채점이 끝난 건만 집계한 결과입니다.

8월 말에 **적중의 정의를 바꿨습니다.** 전에는 "올랐으면 적중"이었는데, 그 기준으로는 아무 판정 없이
올랐을 비율(기준선)과 구분이 안 됐습니다. 지금은 수익률이 그 종목의 평소 변동성을 넘어야 적중으로 셉니다.
그래서 아래 숫자는 7월에 적었던 67%와 **직접 비교할 수 없고** 같은 규칙으로 센 기준선을 다시 산출하기
전까지는 화면에 확률을 제시하지 않습니다. '유지' 판정 4,020건은 방향을 말하지 않으므로 채점 대상이 아닙니다.

| 항목 | 값 | 비고 |
| --- | --- | --- |
| '상승' 판정 채점 완료 | 235건 | 50개 종목 · 2026-07-29 ~ 09-04 |
| 그중 적중(변동성 초과) | 89건 (37.9%) | 부호만 보던 옛 기준보다 훨씬 엄격합니다 |
| 95% 신뢰구간 | 31.9% ~ 44.2% | |
| 기준선 | 재산출 중 | 저장된 값은 옛 정의와 섞여 있어 인용하지 않습니다 |
| 화면 노출 | 보류 | 같은 규칙의 기준선을 넘는지 확인한 뒤에만 |

**AI 모의투자(2026-09 신설)** — 로컬 LLM이 매일 위 판정과 뉴스 라벨을 읽고 가상 1억원을 운용합니다.
판단은 다음 장 시가에 사후 체결되고 검증된 지표 규칙 계정과 나란히 놓입니다. 7월 30일부터 9월 4일까지
30거래일을 리플레이한 결과입니다.

| 계정 | 판단 | 체결(진입/청산) | 자산 1억 → |
| --- | --- | --- | --- |
| EXAONE 직접 판단 | 30회(파싱 실패 1) | 13 / 4 | 0.94억 (−5.5%) |
| 지표 규칙 | 30회 | 38 / 28 | 1.07억 (+7.0%) |

LLM 판단이 규칙보다 뒤졌다는 사실을 그대로 둡니다. 표본 30건 미만이라 적중률 숫자는 화면에 없고
"어느 계정이 무엇을 샀다"는 기록까지만 보여 줍니다.

> 이 서비스는 투자자문업자가 아니며 어떤 종목의 매수·매도도 권유하지 않습니다.
> 제시되는 지표와 판정은 과거 데이터에 기반한 참고 자료이고 투자 판단과 그 결과는 본인 책임입니다.

## 7. 어떻게 만들었는가

1인 개발이며 2026년 5월에 시작했습니다.

판정에 새 근거를 넣을 때는 먼저 과거 데이터로 검증하고 기준에 미달하면 넣지 않습니다.
재무 지표를 방향 판정에 넣으려던 시도는 검증에서 기준을 넘지 못해 **실제로 기각했고**
지금은 참고 서술로만 쓰입니다.

## 8. 앞으로

정해진 출시일은 없습니다. 아래는 우선순위이며 검증을 통과하지 못한 항목은 넣지 않고 기각합니다.

1. **답의 골격을 코드가 쓴다** — 결론 첫 줄·비교표·예산 후보는 이미 코드가 만듭니다. 나머지 서술의 숫자도
   카드와 같은 출처에서만 나오도록 답변 파이프라인을 바꾸는 중입니다(페르소나 QA에서 남은 1건).
2. **기준선 재산출** — 바뀐 적중 정의로 기준선을 다시 세고 넘으면 그때 확률을 화면에 올립니다.
3. **AI 모의투자 표본 쌓기** — 매일 1회 자동 판단이 30건을 넘으면 적중률과 이유별 성적을 공개합니다.
4. **답에 남은 전망 문구 잡기** — 9월 8일 감사에서 서울시 추정매출 "당월" 필드가 분기 합계임을 확인해 월 환산(÷3)으로 고쳤고
   점포 5개 미만은 표본 경고를 붙여 결론에서 뺐습니다. 남은 것은 LLM이 덧붙이는 "성장이 예상" 류 문장을 더 촘촘히 거르는 일입니다.
5. **데이터 공백 메우기** — 사업자 서류가 필요한 출처(임대료 등)는 쓰지 않습니다. 무료 공개 데이터 안에서만 찾습니다.
